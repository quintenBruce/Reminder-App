# Install Remind on Android

I'm sharing my reminder app with you. It works on Android 8 or newer with Google sign-in. There's no iPhone or web version.

1. Download the attached Remind APK, or use the download link I sent.
2. Open it. If Android asks, allow this email/browser/files app to install apps from this source, then install Remind. You can turn that permission off afterward.
3. Open Remind and **Continue with Google**. Choose your name and a unique username. Friends can see these; your email isn't shared with them.
4. Allow notifications. In Remind Settings, enable exact alarms for more reliable timing. Use the test notification to check delivery.
5. Tap my invitation link, then **Add Friend**. If you opened the link before installing, tap it again now. If it keeps opening the browser, enable supported links under Android Settings → Apps → Remind → Open by default.

Try: **“Remind me and @username to call tomorrow at 6 PM.”** Check the people and time shown, then tap **Create**.

Shared reminders are editable by everyone included. **Done and Remind me later affect only you.** You can leave a shared reminder without deleting it for others. **Delete for everyone** removes it for all participants. Removing a friend preserves existing shared reminders.

For rare urgent reminders, select **Priority alarm** before Create. This requests a fullscreen alarm when Android permits it; enable fullscreen access if prompted. On an unlocked phone Android may show a prominent notification instead. It does not automatically override Do Not Disturb. Each person can choose normal/priority alerts, or follow the shared setting, from the reminder's menu.

The app has a shared daily AI allowance. If it says the limit is reached, try after the displayed reset time. Existing reminders still work. Keep internet access for creating, editing, and receiving shared changes; reminders already synced to your phone have a local alarm fallback.

For updates, install the newer APK I send over the existing app. Please send me your phone model, Android version, what you tried, and any error text if something fails. You should never need to send me a password or a Firebase/debug token.
