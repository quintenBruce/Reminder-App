# Install Remind

1. Download and open **app-debug.apk**. Allow installation from your email/browser if Android asks.
2. Open Remind, sign in with Google, and choose your name and username.
3. In Remind Settings, enable notifications and exact alarms. Send a test notification.
4. Tap my invitation link, then **Add Friend**. If you opened it before installing, tap it again now.

Try: **“Remind me and @username to call tomorrow at 6 PM.”** Check the names and time, then tap **Create**.

Everyone can edit a shared reminder. **Done and snooze affect only you.** Leave stops your alerts; Delete for everyone removes the reminder for all participants.

**Priority alarm** requests fullscreen alerts when Android allows them. Enable fullscreen access if prompted. You can override priority for yourself from the reminder menu; it does not automatically bypass Do Not Disturb.

For updates, install the newer APK over the old one. If you hit the daily AI limit, try after the displayed reset time—existing reminders still work.

Android 8+ with Google sign-in is required. If an invitation keeps opening in the browser, enable supported links in Android Settings → Apps → Remind → Open by default. Send me any error text if you get stuck; no passwords or debug tokens are needed.
